# SAHAYAK-AI (Next.js v2)

> **AI-Enabled Real-Time Stress and Trauma Assessment Module**  
> For National Helpline Against Atrocities (NHAA — 14566)

This project has been completely rebuilt in **Next.js 16 (App Router)** with a brand new, highly polished UI matching modern production-grade dashboards.

## 🚀 Quick Start
```bash
cd sahayak-v2
npm install
npm run dev
```
Runs on `http://localhost:3000`

## 🎨 New Design System: "Calm Authority with Warmth"
- **Primary:** Deep Indigo (`#000666`) for trust and government authority.
- **Secondary:** Saffron (`#944b00`) for warmth and empathy.
- **Urgency:** Crisis Red (`#ba1a1a`) for critical alerts.
- **Backgrounds:** Soft warm parchments and glassmorphism UI elements.

## 📱 Modules Built
1. **Crisis Console (`/`)**: Main operator dashboard with live queue, SVI radial gauges, and SHAP explainability charts.
2. **SVI Telemetry (`/telemetry`)**: Advanced analytical view for a critical suicidal ideation case with live trajectory charts.
3. **KAVACH Hotspots (`/hotspots`)**: Predictive geospatial risk map identifying vulnerability zones.
4. **Victim Sanctuary (`/sanctuary`)**: The citizen-facing portal featuring e-FIR filing, SAATHI AI Chat, and multilingual support.
5. **Mobile Panic (`/mobile`)**: A live interactive mobile emulator showing the 3 phases of the biometric SOS trigger, paired with the IVRS pipeline view.

*Built for the Smart India Hackathon Grand Finale.*
